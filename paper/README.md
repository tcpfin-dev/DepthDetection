# Short paper (IEEE conference format)

`paper.tex` is the 4-to-5 page manuscript for the project described in
`../AGENTS.md`. `paper.pdf` is the built result (5 pages: 4 pages of content
plus the references page).

## Build

```sh
cd paper
pdflatex paper
pdflatex paper          # second pass for cross-references
```

`IEEEtran.cls` is vendored in this folder, so no TeX Live publisher packages are
required. If LaTeX is missing on a fresh box:

```sh
pacman -S texlive-latex texlive-latexrecommended texlive-fontsrecommended
```

## Figures

`figs/` is generated, not hand-made. Regenerate from the evaluation CSVs:

```sh
cd .. && ./venv/bin/python paper/make_paper_figures.py
```

| file | content | source |
|---|---|---|
| `fig1_pipeline.png` | method schematic (drawn with matplotlib) | — |
| `fig2_qualitative.png` | mug success / tall-bottle failure, RGB + depth + sized output | `outputs_clean/large/...` and `dataset/...` |

## Numbers

Every table and every figure value comes from `outputs_clean/`, regenerated by

```sh
python test_pipeline.py --dataset dataset --depth-model all --calib inverse \
    --yolo yolov8m.pt --out outputs_clean
```

`../wrapup.md` is the analysis write-up behind the paper; the reported metrics
(MAE, RMSE, signed bias, W/H errors, per-light and per-object breakdowns, the
error shares, and the depth-sampling ablation) were all re-checked against
`outputs_clean/eval_per_image.csv`.

## Before submitting

- Replace the `\author{...}` block: name, department, city, email.
- Add the venue's copyright/notice block if the call for papers requires one.
- The PDF is 5 pages including references; a 4-page-only venue needs about two
  further lines trimmed (the last conclusion paragraph is the cheapest cut).
